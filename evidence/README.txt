EVIDENCE FOLDER: what goes here
================================

The Evidence Archive page (evidence.html) lists each document with its status.
Every row marked "On request" turns into an "Open file" link by itself as soon
as a file with the matching name exists in THIS folder on the published site
(js/evidence.js checks for it on page load; nothing else needs editing).

Expected file names (exactly as written):

  training-and-supervision-plan.pdf        Training and Supervision Plan (TSP)
  activity-plan-9-month-attachment.pdf     Activity plan attached to the 9-month assessment
  go-no-go-report.pdf                      Go / No-Go report, 15 April 2024
  nine-month-assessment-form.pdf           9-month assessment form
  training-form-ec-record.pdf              Individual training elements form (EC record)
  4dsound-certificate.pdf                  Certificate, 4DSOUND week, May 2023
  atlab-i-secondary-analysis-v1-1.pdf      AT-LAB I secondary analysis, v1.1
  atlab-methods-manuscript-october-2026.pdf  AT-LAB methods manuscript, October 2026
  atlab-project-description-june-2026.pdf  AT-LAB project description, June 2026
  data-management-plan.pdf                 Data management plan
  cv-2026.pdf                              CV

Before you put anything here, remember that GitHub Pages is public.
Anything in this folder can be opened by anyone with the link, and a PDF stays
retrievable even if the page stops linking to it. Publish only what you are
comfortable having public:

  - Forms that carry supervisors' names, signatures or evaluative comments
    (Go / No-Go, 9-month assessment): check with the supervisors, or publish a
    redacted copy, or leave the row as "On request".
  - Anything with participants' responses (the AT-LAB I forms): only aggregated
    or anonymised material, in line with the data management plan.
  - The training form and certificates: remove personal data you would not
    put on a public page (addresses, ID numbers, signatures).

A row with no matching file simply stays "On request". That is a legitimate
state for the defence: the committee can ask for the document.
